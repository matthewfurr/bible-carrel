When one note was changed on two devices

A note on John 15:5 was edited on the iPhone and on the Mac before they synced. iCloud keeps one; the app keeps the other too. This is how you would see and settle it. The notes are made up.

The note shows the version iCloud kept, with a small “2 versions” mark, never an alert and never red. Clicking the mark shows both, each with its device and time. Use This One swaps them (the other becomes the kept one, so nothing is thrown away by choosing). Keep Both in the Note puts the kept text under the current text in one note. Discard removes the kept version and can be undone. The same mark and the same three choices are on the iPhone’s note sheet and in the Notes Browser, which also gets a filter showing only notes with a kept version.
